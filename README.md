# CEPHAS AI PowerOps

Enterprise distribution-network intelligence for electricity distribution utilities.

PowerOps provides advisory intelligence for feeder and transformer performance, asset health, anomaly detection, predictive maintenance, and operational prioritisation. It distinguishes source measurements, engineered features, model outputs, and engineer-validated conclusions.

## Development status

Initial repository bootstrap. No utility integrations or production capabilities are claimed at this stage. The first implementation phase establishes architecture, security boundaries, data contracts, and automated quality gates.

## Deployment model

Designed for customer-controlled, customer-hosted deployments with annual signed CEPHAS licensing. Deployment details and integrations are subject to customer discovery and approval.

## Safety boundary

The initial product is advisory only. It does not issue switching, protection, dispatch, or other operational control commands.
